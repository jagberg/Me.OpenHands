# ignite-brief
Read the ticket, docs/spec.md and the code (not `qa/`). Write `.ignite/brief.md` with: Problem, Requirements (bullets), Acceptance criteria (bullets), Open decisions.
If QA reported a GAP, add the missing requirement and note 'revised after QA'. Do not change code in this step.
